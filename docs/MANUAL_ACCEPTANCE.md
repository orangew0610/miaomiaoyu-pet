# Windows 手动验收清单

每个发布候选版本记录 Windows、缩放、显示器、VSCode 和 Python 版本。

- [ ] 冷启动后角色素材完整，idle 动画正常。
- [ ] 随机移动、跳跃、拖拽、抛物线和右键菜单正常。
- [ ] 主屏及副屏边缘不会使桌宠永久丢失。
- [ ] 打开代码检查器、本地 pyflakes 检查和行高亮正常。
- [ ] 模型请求期间动画和窗口拖拽保持流畅。
- [ ] 连续发送两轮聊天，请求中当前用户消息只出现一次。
- [ ] 未授权代码上传时，任何诊断事件都不含源码正文。
- [ ] API 密钥不出现在配置 JSON、日志和 Git diff 中。
- [ ] VSCode 新增 error 触发一次提示，重复事件受冷却限制。
- [ ] 旧文档版本事件被拒绝，error 消失触发修复庆祝。
- [ ] IPC 断开后扩展能重连，桌宠退出不影响 VSCode。
- [ ] PyInstaller 产物在未安装 Python 的 Windows 环境启动成功。
